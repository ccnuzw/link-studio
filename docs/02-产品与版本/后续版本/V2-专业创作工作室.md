# V2 专业创作工作室

## 目标

在 V1 本地项目、资产、生成任务和媒体输出稳定后，完整迁移并完善 `video-canvas` 的短剧/分镜、营销工作台和 3D 导演台等专业创作域。

## 规划范围

- 完整剧本分析、角色/场景/道具资产与分集管理。
- 分镜表与图像/视频生成节点的可靠关联。
- 营销项目、多平台内容与模板化输出。
- 3D 场景、摄影机、运镜预演和镜头参数输出。
- 更多视频/音频 Provider 适配及专业生成参数。
- Agent 通过结构化操作协助组织画布和分镜。
- 图片扩图/涂鸦/裁切、提帧/拆图等现有媒体工具，以及旧 Web 项目包显式导入。
- 全部 Provider 插件分批兼容，不能以首版几家样例替代完整生态目标。
- 首页快速创作/独立会话、个人资产复用、模板交换和画布提醒/桌宠的桌面适配；专业域同步迁入技能场景、环节提示词、片场多 take 及模型提示词转写。

子能力、上游源码依据和逐批文档工作包以 [子能力补充与渐进落盘计划](../../04-技术架构/子能力补充与渐进落盘计划.md) 为准。用户可浏览的版本历史仅为待评估候选；通用技能脚本执行是上游已搁置规划，不因本次登记自动列入 V2。

## 不包含

- 官方服务组织与共享同步（V3）、多人实时同编、工作室自托管。
- 专业多轨剪辑器不是上游导演台/短剧合成的既有事实，不因“整体迁移”默认增加。

## 建议推进方式

建议先迁角色/分镜与基础媒体工具，再迁完整短剧、营销和导演台；每个域可独立成批，不要求一次写完全部功能规格。明确来源、依赖和验收后即可进入该批设计，具体优先顺序保留 V1 反馈调整。

V1 已有共享引擎和设置/核心画布助手；V2 扩展角色/分镜/短剧等专业域上下文、工具、技能和审批，不是首次引入画布 Agent。每域人工流程与上游已有助手路径同步验收。能力/源码见 [迁移台账](../../04-技术架构/上游能力迁移台账.md)。

## 进入条件

- V1 项目格式、资产引用、画布保存与任务状态稳定。
- 至少一个完整本地生成到导出的主链路通过版本门禁。
- 各创作域完成用户流程审查和独立功能规格。

## 暂不冻结

具体域的优先顺序、V2 功能编号、3D 导演台深度和 Agent 运行时选择，需基于 V1 使用反馈单独规划。
