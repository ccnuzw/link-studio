# V3 共享空间与组织

## 目标

允许用户将本地项目主动创建为 Link Studio 官方共享空间项目，在不同设备继续创作，并由官方账号/组织能力管理成员和官方服务使用策略。

## 规划范围

- 用户显式发布本地项目，项目结构和媒体资产分层同步。
- 大文件按需同步、断点续传、冲突发现与显式解决。
- 组织/工作室、成员角色、官方模型权限、预算和审计。
- 公司工作未完成时，用户可在家中另一设备恢复项目。

## 进入条件

- 本地项目格式有稳定版本化策略。
- 项目修订、资产 Blob、任务记录和用户身份的归属关系已定义。
- 官方服务具备可靠对象存储、幂等同步和审计基础。
- 官方账号与空间授权先明确；个人跨设备继续创作不要求用户必须加入组织。

## 建议推进方式

先做用户主动创建共享空间、项目清单/Blob 分层同步和跨设备继续创作，再扩展组织/角色/官方资源策略。稳定 V1 项目格式即可作为同步设计基线，V2 域新增结构按 schema 演进适配，无需等所有专业域迁完才启动 V3。

本地绝对路径、插件启用授权、个人 Provider 密钥和敏感任务句柄不默认同步；新设备重新绑定模型与外部引用。预留稳定 ID 不等于同步/冲突协议已经完成。

## 不预设

- 不承诺多人实时协同。
- 不把用户个人 Provider 密钥默认同步给组织或其他设备。
- 组织是否能要求成员使用官方模型，由后续权限策略规格定义。
