# V1 产品需求

## 目标

交付可安装的 Link Studio 桌面创作工具，用户即使未登录也能在本机创建项目、组织素材、使用本地自定义模型完成生成并输出基础视频作品。

## 用户与价值

- 个人创作者：项目和素材留在本机，自主选择自定义 Provider。
- 视频创作团队成员（后续）：通过可迁移项目结构为共享空间做准备，但 V1 不提供同步。

## 核心主线

创建项目 → 导入脚本和媒体 → 在画布组织节点 → 配置/选择本地 Provider → 发起生成 → 结果进入资产库并关联节点 → 预览并导出。

## V1 首阶段需求

1. 项目能在本地创建、打开、保存并恢复；同一项目只有一个可写窗口，重复打开激活已有窗口或提示占用。
2. 用户能把媒体导入项目资产并在画布中引用。
3. 画布能创建/编辑/连接主要创作节点并持久化。
4. 用户能安全配置本地 Provider，无需登录。
5. 可人工或借助内置 Agent 配置 Provider 插件；插件经审阅批准后才能执行。
6. 生成任务可追踪、可恢复，输出与项目节点和资产关联。
7. 用户能预览媒体、排列视频镜头顺序、添加可选 BGM，并拼接导出为 MP4。

8. 设置与画布内置 Agent 共用可恢复会话/工具引擎，保留上下文、插话、审批、计划/卡片、技能/受限 code-mode 和运行反馈。
9. 设置 Agent 能查现状、辅助模型/插件接入、出字段级变更单、安全填密钥与试跑诊断。
10. 画布 Agent 能理解选择/引用、按需读取、组织/编辑/布局、申请生成/删除、等待结果回同会话、冲突感知撤销；核心路径进入 V1，专业域随域迁移。

最终目标是主线与主要功能尽可能完整覆盖；分阶段不是删除功能。桌面不适用或与既有设计冲突的例外须登记原因、去向和替代。

## 后续阶段

- 官方模型与积分消费：须先冻结官方请求执行、密钥、结算与失败补偿。
- 完整短剧工作室、营销工作室和 3D 导演台。
- 共享空间与跨设备同步、组织成员及预算策略。

## 非目标

- 代码仓库/终端作为产品中心。
- 工作室自托管。
- V1 多人实时协同。
- 将所有 video-canvas 服务端代码塞入桌面安装包。
