- 本地证据与准确命令见 [M0-05 实测记录](../../04-技术架构/实施基线与开发批次.md#11-m0-05-实测记录)：本地 9 项、迁入上游 144 项、全量 58 项集成、源码/目录包各 3 项 Electron 测试通过。

- V1-FR-006：规划中 → 开发中；`packages/media-runtime/` 已实现真实 FFmpeg 子进程导出，仍无用户导出入口或预览能力。

- 二进制选型：排除两个含 nonfree 的候选，从固定 FFmpeg 源码构建最小 LGPL 版本，随包保留源码/许可/构建信息；未验证平台不开放。系统 VideoToolbox 可用性和正式分发审查仍是后续门禁。
- M0-01～04 已有本机范围证据，M0-05 共享 Agent runtime 未完成，M0 整体仍未通过。下一项为 Pi Durable engine/store、SQLite/QuickJS、流式模型工具及恢复验证。
