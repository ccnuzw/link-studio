# V1 版本总览：桌面本地创作闭环

## 目标

将 `video-canvas` 的视频创作核心能力逐阶段迁入 Link Studio 桌面端。V1 首阶段交付不依赖登录/云服务的本地项目、画布、资产、自定义模型生成和基础导出闭环；V1 后续阶段再接官方模型和更完整的创作域。

## 范围

### 首阶段交付

- Electron 桌面运行、项目创建/打开/恢复；同项目单写窗口。
- 项目素材导入、资产预览和引用。
- 无限画布的核心节点、连线、分组与自动保存。
- 可扩展本地 Provider 插件，支持人工编辑和 Agent 辅助草拟；用户批准后启用，允许未登录使用。
- 统一生成任务状态、取消/重试边界和生成结果入库。
- 共享 Pi Durable 引擎与设置/核心画布双入口 Agent：上下文、变更单、结构化工具、审批/任务等待、插话、恢复、撤销、技能/code-mode 和运行反馈。
- 基础视频预览、镜头顺序拼接为 MP4 和可选 BGM。

### V1 后续阶段

- 官方账号、官方模型目录和消费。模型执行、官方凭证与积分结算契约冻结后再拆规格。
- 更多已通过兼容验证的 Provider 插件；完整短剧、营销、导演台和高级媒体工具统一在 V2 迁移。

## 不在 V1

- 共享空间、跨设备同步和多人实时协作（后续版本规划）。
- 官方后台组织/工作室成员管理（后续官方服务规划）。
- 工作室自托管及工作室 Provider 来源。
- 一次性迁入所有上游协议插件和全部高级媒体工具。

## 交付阶段建议

| 阶段 | 目标 | 退出条件 |
| --- | --- | --- |
| V1-A 桌面与本地项目 | Electron 壳、本地项目、恢复、素材导入 | 重启可恢复项目和资产引用，断网仍可编辑 |
| V1-B 画布与自定义模型 | 核心画布交互、Provider 配置和一条生成链路 | 未登录完成一次生成并把输出绑定节点 |
| V1-C 视频输出 | 预览、镜头顺序拼接 MP4 和可选 BGM | 镜头顺序、音画同步和 BGM 时长正确，导出可播放且 UI 可响应 |
| V1-D 本地版验收 | 端到端、故障恢复、目标平台与安装包 | 本地闭环可交付；完整创作域不阻塞本批，统一进入 V2 |
| V1-E 官方模型 | 官方登录、模型目录、任务与积分 | 单独 ADR、资金/权限技术设计和服务端对账 AC 通过 |

阶段先后是建议；V1-E 不得早于官方模型安全和结算决策。

工程批次 M0、S1～S7 及每批进入/完成条件见 [实施基线与开发批次](../../04-技术架构/实施基线与开发批次.md)。V1-D/V1-E 为产品交付阶段，S1 等为工程拆分，不是额外版本号。

## 开发门槛

- 每项功能规格从 Draft 进入 Ready 前，接口、数据、错误行为、AC 和测试资产必须明确。
- 高风险功能具有独立技术设计和分支到测试追踪。
- 首阶段端到端验收覆盖：新建项目 → 导入素材/脚本 → 画布组织 → 自定义模型生成 → 结果入库 → 导出。
- 官方模型、共享空间和组织能力不作为首阶段发布阻塞项。
- V1-E2E-02 为首阶段发布门禁；设置/核心画布助手不能降为只迁聊天框或 Provider 作者。V2 专业域 Agent 随对应域验收。
