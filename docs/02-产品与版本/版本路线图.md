# Link Studio 版本路线图

| 版本 | 主题 | 核心目标 | 规划文档 |
| --- | --- | --- | --- |

## 版本边界

### V1 桌面本地创作闭环

- 做：桌面壳、本地项目和资产、创作画布、自定义 Provider、任务恢复、基础视频预览/导出。
- 本地发布闭环为核心四类节点、Provider 插件、共享引擎及设置/核心画布双助手、生成入库、顺序拼接 MP4 与可选 BGM；专业域归 V2，并同步迁入对应助手工具。
- 后续阶段做：官方模型/积分；接入前需 ADR 和技术设计。
- 不做：共享空间、组织、多用户协同、自托管。
- 成功标准：未登录可从空项目完成自定义模型生成并导出可播放媒体。

### V2 专业创作工作室

- 做：逐步补齐 video-canvas 的短剧、分镜、营销和导演台能力。
- 依赖：V1 项目、资产、画布、任务和媒体输出稳定。
- 不做：组织/共享空间、实时协同、工作室自托管；这些能力不作为 V2 创作域迁移前置。
- 进入条件：对应域的迁移台账已展开，数据/API/交互/AC 就绪；V1 本地闭环通过验收。无需等官方计费先完成。

### V3 共享空间与组织

- 做：官方共享空间、跨设备继续创作、组织成员和策略。
- 依赖：本地项目 schema 稳定、资产同步和冲突解决设计完成。
- 不做：工作室自托管；多人实时同编暂不承诺。
- 进入条件：官方身份/空间授权/对象存储可用、同步冲突与迁移规格就绪；可以基于稳定 V1 项目格式独立于 V2 领域 UI 推进。
