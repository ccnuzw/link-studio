## 1. 分层与命令

| 层级 | 计划命令 | 核验对象 |
| --- | --- | --- |
| 类型/边界 | `pnpm typecheck`、`pnpm lint` | main/preload/renderer 依赖和编译；安全边界另有负向测试 |
| 单元与服务 | `pnpm test <test-file>` | schema、规范编码、hash、revision、状态机、幂等、URL 策略 |
| 集成 | `pnpm test:integration`；定向使用 `pnpm exec vitest run --project integration <test-file>` | 已建立存储/Provider/FFmpeg/Agent 与产物检查（产物检查需先 build）；完整业务接入待建 |
| Electron E2E | `pnpm test:e2e tests/e2e/desktop.spec.ts`；后续新增 local-creation.spec.ts | 当前验证桌面工程；无登录创作与退出/恢复主链路待建立 |
| 打包 | `pnpm package:mac` / `pnpm package:win` | 安装包资源、子进程、二进制路径和权限；签名验收另行记录 |

首批主入口资产：`src/main/services/linkStudio/projectStore.test.ts`、`projectOwnership.test.ts`、`assetStore.test.ts`、`assetImport.test.ts`、`assetReference.test.ts`、`src/main/ipc/linkStudioProjects.test.ts`、`tests/integration/projectOwnership.test.ts`。命令按根脚本转发过滤参数，不依赖不存在的隐式工作目录。

## 2. 可复用测试样本

| 样本 | 内容 | 断言 |
| --- | --- | --- |
| project-v1 | 空项目、含素材项目、未知扩展/节点、上代有效+末尾损坏、链分叉和高版本 | 保留/拒绝语义；hash/父链；无静默丢字段 |
| file-faults | 无写权限、空间不足、Blob 完成后/快照发布前/发布后响应前故障 | 最后有效状态恢复；幂等不重复；不登记半成品 |
| ownership | 同路径/符号别名/大小写别名、不同目录同 projectId、双进程同时打开、进程崩溃 | 单 writer；不同目录可独立；旧 owner 不能迟到提交 |
| assets | PNG/JPEG/WebP、损坏伪扩展、超限模拟流、相同 hash 独立记录、移动/变更的外部引用 | 内容校验、内存受限、默认复制独立性、引用 hash 匹配 |
| media | 合成生成带可区分帧/时间码的两段视频，帧率/尺寸不同、无音轨；长/短合成音频 | 顺序、比例、时长、音画同步、BGM 不改变视频长度 |
| provider-mock | sync text/image、async video、prepare/upload、query、cancel、超时已受理、下载过期/重定向 | hooks/state/认证不泄漏、未知不重提、恢复只 query/download |
| plugin-hostile | 无限循环、大输出、非 JSON、试图读取 fs/net/env/secret、畸形 manifest | 可终止、资源限制、无直接宿主权限 |
| agent-config | 无文本模型、有效手工模型、API 文档样例、含假密钥文本 | 不循环依赖；秘密脱敏；草稿工具不能静默启用/执行 |

媒体用自生成图形/音调，避免依赖未知版权素材或真实用户数据；大文件限制用稀疏/模拟流测试加一份真实中等媒体，不要求测试库提交 20 GiB 文件。

## 3. 必测失败路径与批次出口

- S1：IPC 未授权、token 跨窗口/过期、非法/重复目录、锁竞争、旧 owner、schema 新版、坏尾快照、revision 冲突、operationId 重用、复制取消/失败、重复内容、引用变更、被引用资产移除。错误必须映射 API 的稳定 code，不能只断言“抛异常”。
- S2：首批节点保存/恢复、边和分组约束、未知节点保留、删除节点后任务历史、自动保存失败 dirty buffer、后台结果与当前编辑不互相覆盖。
- S3：安全存储失败拒绝明文、secret 输入后清空和日志脱敏、插件 hash 改变重新启用、受控 endpoint、恶意脚本限制；人工与 Agent 共享校验。
- S4：sync/async 正常输出、提交结果未知、可查询任务重启、下载/入库崩溃、节点删除、并发输出、取消与真实终态一致。真实供应商差异单列，不以 mock 代替真实兼容声明。
- S5：混合参数顺序合成、无音轨、BGM 长短、输入快照、被 pin 资产移除保护、进程取消、磁盘不足和覆盖保护。用 ffprobe/帧/音轨断言，不只看退出码。

开始实现不要求预先创建并通过所有测试；但本批出口必须有相应可执行证据。后续批次验证失败不能通过“修改预期为当前实现”规避已经确认的产品行为。

## 5. 平台与证据边界

M0 优先 macOS Apple Silicon，后续 macOS Intel/Windows x64 分别验证锁、文件发布、safeStorage、插件 runner 和媒体二进制。未运行平台明确写未验证。FFmpeg 编码器/许可证、安装包签名和更新源在分发前验收，不以本机开发运行代替。

本地 mock 证明宿主行为，真实 Provider 验证证明某模型/插件版本/端点的实际兼容，两种证据分开。没有本轮用户请求不执行收费调用或发布安装包。
