# V1 Agent 端到端验收规范

## V1-E2E-02 设置/画布双入口 Agent 辅助与恢复

覆盖 V1-FR-003～005、V1-FR-007～009，发布门禁 V1-RG-004。目标测试 `tests/e2e/agent-assistance.spec.ts`，计划命令 `pnpm test:e2e -- tests/e2e/agent-assistance.spec.ts`。证据状态：未创建。

### Given

未登录本地环境，已有人工配置的可用 mock Agent 模型（支持流/tool calling，另有视觉样例）及 mock 媒体 Provider；测试目录含固定图片/视频/文档。禁用官方服务访问，保留本机 mock。记录模型 main/summary/title/activity 调用与目标工具执行次数，不用真实收费调用证明基础机制。

### When

1. 设置页选择模型/插件，打开助手，移除一个上下文标签后提出接入/参数调整任务。助手查现状/资料、显示计划/活动、创建多项字段变更单。
2. 用户人工修改一项基线，再批准变更单中的部分项。验证 stale、未选择和成功项分别显示；专用密钥框提交假密钥，确认 dry-run/真实试跑路径分离。
3. 打开项目画布，选节点/组、@ 引用并要求组织素材、修改文案和布局。助手先读再改，用户并行编辑一个目标触发冲突保护，验证效果可定位。
4. 助手申请生成，显示模型/目标/数量/输入/费用边界；用户批准后只创建原始任务。收起面板，发送插话，模拟丢完成通知并重启 engine。
5. 恢复原任务 query，整批结果回原会话一次。验证 watch、活动/卡片、结果资产和节点历史；助手停止或项目关闭时不通过旧 owner 写入。
6. 用户请求本轮撤销，其中一个节点已有后续人工修改；安全项撤销，冲突项报告并保留人工修改，已发生外部生成/费用不宣称撤销。

### Then

- 两入口共用 engine/UI 机制且 scope 严格隔离，不要求官方登录；收起不停止，退出/停止行为真实。
- 配置动作实际执行、可逐项批准、基线重新检查；秘密不进入模型/聊天历史/插件/项目/默认 trace。
- 画布动作经结构命令和目标 receipt，故障后不重复改图、不第二次 submit；只迁聊天或插件作者不得通过。
- 上游机制覆盖包括事件回放、提问/计划/卡片、插话、审批、watch、上下文/能力过滤、冲突感知撤销和观测；各类失败分别有集成测试。
