# V1 端到端验收规范

## V1-E2E-01 新建项目到生成并导出视频

覆盖 V1-FR-001～006，发布门禁 V1-RG-001～003。目标资产为 `tests/e2e/local-creation.spec.ts`，计划命令 `pnpm test:e2e -- tests/e2e/local-creation.spec.ts`。证据状态：未创建。

### Given

用户未登录官方服务；本机可写临时目录；已准备两个可区分的视频/参考图片及长短音频样本；本机 mock Provider 提供文本、图像和可查询异步视频能力，响应/输出固定可复现。阻断官方服务域访问但允许本机 mock，验证的是不依赖官方服务，不声称断网能调用外部云模型。

### When

1. 启动桌面应用，新建项目，默认复制导入参考素材；移动源文件后重开，项目素材仍可用。
2. 创建 script/image/video/audio 核心节点及分组、连线；保存并重开，布局/引用/viewport 一致。
3. 人工选择内置插件配置文本模型；用配置 Agent 按 mock 文档创建另一个 Provider 草稿，校验、查看差异并启用，手工输入假测试密钥。
4. 从视频节点提交异步任务，拿到 handle 后退出，重新启动并恢复 query；从 mock 断言没有第二次 submit。
5. 视频结果写入资产并追加到来源节点；用户选择生成结果与另一视频，调整顺序，选择可选 BGM 导出 MP4。
6. 导出期间修改项目镜头列表，验证本次输出仍使用启动快照。重启后项目/结果/配方和导出结果记录可读。

### Then

- 全程本地功能不要求官方账号或官方 API；模型来源与数据发送目标清楚。
- 项目/资产/节点历史可恢复，submit 未重复；密钥不出现在项目快照、日志、插件、Agent 上下文或读取 API。
- MP4 容器、镜头顺序、时长、音轨及 BGM 行为由可执行断言验证；任务运行不阻塞窗口导航/取消。
- 同实例重复打开激活原窗口；另实例占用不能获得第二个写入口。

### 配套失败场景

提交已受理但响应丢失 → outcome_unknown 且不自动重发；导入或导出取消 → 不产生伪成功记录；目标存在 → 未确认不改成品；项目保存失败 → 保留最后有效版本及当前 dirty 修改。分别复用功能 AC 集成测试，不将全部故障塞进一条长 E2E。

### 验证限制

mock 视频与配置助手测试覆盖产品/宿主协议，不证明真实云模型画质或实际插件厂商兼容。另行登记真实供应商/模型/插件 hash 的验证结果；真实收费测试不作为无账号首次开发的前置条件。
