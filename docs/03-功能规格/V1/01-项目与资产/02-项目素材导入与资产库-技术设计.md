# 02 项目素材导入与资产库 - 技术设计

来源：[需求](02-项目素材导入与资产库.md#需求说明) · [接口](02-项目素材导入与资产库.md#接口契约) · [数据](02-项目素材导入与资产库.md#数据与事务) · [验收](02-项目素材导入与资产库.md#验收标准)

## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 大文件导入造成内存峰值 | 高 | 流式复制、受限并发、分块 hash | D001 |
| 半成品被登记或覆盖 | 高 | 临时 Blob 校验后提交记录 | D002 |
| 删除引用资产导致项目损坏 | 高 | 维护引用索引或导入时校验引用 | D002 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `importAsset(projectId, token, mode = copy)` | 有效授权 token | ready AssetRecord | copy 写项目 Blob；reference 保存授权定位符 | 相同 hash 提供复用或独立记录选择 |
| `removeAsset(projectId, assetId)` | 资产存在 | 移除/软删除结果 | 更新索引/清理项目 Blob | 是 |

## 伪代码

```text
FUNCTION importAsset(project, token, mode = copy):
  IF token not authorized: RETURN ASSET_PATH_DENIED           // B02-01
  IF type or size invalid: RETURN ASSET_INVALID               // B02-02
  IF mode is copy: stream to temporary blob and compute hash; ELSE validate reference and compute hash // B02-03
  IF duplicate found: ask reuse or independent record; never overwrite silently // B02-04
  IF mode is copy: atomically move blob; persist record with explicit mode // B02-05
  generate thumbnail best-effort
  return ready asset

FUNCTION resolveReference(asset):
  IF external source missing: mark missing and request user relocation // B02-06
  IF relocated content differs: reject silent replacement; return explicit conflict // B02-07
  persist validated locator; never delete external source      // B02-08
```

## 并发控制

同一 hash 的并发导入由项目协调器串行检查；复用 Blob，不静默合并用户选择保留的独立资产记录。提交使用 expectedRevision 和 operationId；复制期间发生更新先进入冲突会话，再基于最新状态重提提交，不重新复制。

## 事务边界

采用“暂存文件 -> 校验 -> 完成 Blob -> 发布含资产记录的 ProjectState”的可恢复协议；提交点、去重回执、tombstone 与引用保护见 [本地数据契约](../../../04-技术架构/本地项目与资产契约.md)。S1 不自动删除原始 Blob，避免破坏历史快照；只清理已确认无运行任务使用的 temp/cache。

## 幂等与重试

以 projectId + SHA-256 + import mode 作为去重候选键；相同内容允许复用已有资产或创建独立记录，均不覆盖既有记录。Blob 可按 hash 共享，清理需检查所有记录和创作引用。

## 外部调用与补偿

不适用：首阶段本功能仅本地处理；媒体解析器仍需限制资源消耗。

## 安全与日志

- 只接受 Main 创建的文件授权句柄。
- 不信任扩展名；校验签名/容器元数据并限制资源。
- 日志记录 assetId、错误类型和字节数，不记录媒体正文或凭证。

## 发布与回滚

- AssetRecord schema 带版本。
- 缩略图可重建；原始资产 Blob 不随缓存清理。
