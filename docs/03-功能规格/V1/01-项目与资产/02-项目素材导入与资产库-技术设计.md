# 02 项目素材导入与资产库 - 技术设计

来源：[需求](02-项目素材导入与资产库.md#需求说明) · [接口](02-项目素材导入与资产库.md#接口契约) · [数据](02-项目素材导入与资产库.md#数据与事务) · [验收](02-项目素材导入与资产库.md#验收标准)

## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 大文件导入造成内存峰值 | 高 | 流式复制、受限并发、分块 hash | D001 |
| 半成品被登记或覆盖 | 高 | 临时 Blob 校验后提交记录 | D002 |
| 删除引用资产导致项目损坏 | 高 | 维护引用索引或导入时校验引用 | D002 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `selectMedia(projectHandle, multiSelect)` | 活跃窗口项目会话 | 绑定窗口/项目的短期文件句柄 token | 打开系统 picker 和持有 fd | token 单次用于首次提交；同 operationId 提交重放不需 token |
| `startImport/getImport/cancelImport` | 活跃窗口及项目，启动时消费文件授权 | 会话 ID、复制字节数与导入结果 | 分块写入暂存文件，终态回收句柄 | 同启动操作同请求返回同一会话 |
| `commitImport(operationId, expectedRevision, importSessionId, choice?)` | 暂存完整，修订匹配 | 新 revision 与资产回执 | 发布 Blob 或 locator，提交原子快照 | 同 ID 同请求重放，变更参数拒绝 |
| `getAssetPreview(projectHandle, assetId)` | 素材可访问，hash 已验证 | 窗口内限时资源 URL | 允许分段读取 | 重新签发时旧授权失效 |
| `relocateAsset(projectHandle, assetId, fileToken)` | 外部引用及新文件授权，内容相同 | 同一素材恢复可用 | 替换设备 locator 文件 | 每次消费一次授权 |
| `removeAsset(operationId, expectedRevision, assetId)` | ready 资产、无 canvas/composition/job 引用 | tombstone + revision | ProjectState 快照；不删除 Blob/源文件 | 回执绑定 assetId |

## 伪代码

```text
FUNCTION stageImport(project, fileToken, operationId):
  IF token owner/project/expiry invalid: RETURN TOKEN_INVALID_OR_EXPIRED // B02-01
  IF extension, regular-file, size or media signature invalid: RETURN ASSET_* // B02-02
  stream fd to project tmp, hash and probe; reject source mutation          // B02-03
  IF cancelled or write failed: discard staging, do not commit               // B02-13

FUNCTION commitImport(project, importSessionId, expectedRevision, choice?):
  IF expectedRevision stale: RETURN conflict; retain staging                 // B02-09
  IF hash duplicate and no choice: RETURN candidates without commit         // B02-04
  IF copy: validate content-address directory and durably publish Blob        // B02-05
  IF reference: durably bind device locator                                  // B02-08
  publish AssetRecord + operation receipt in one ProjectState snapshot       // B02-10
  IF cancelled after commit: RETURN imported                                 // B02-14

FUNCTION removeAsset(project, asset):
  IF any persisted project domain references asset: RETURN ASSET_IN_USE      // B02-11
  tombstone AssetRecord; retain Blob for historical snapshots               // B02-12

FUNCTION resolveReference(asset):
  IF external source missing: mark missing and request user relocation      // B02-06
  IF relocated content differs: reject silent replacement                   // B02-07
  persist validated locator; never delete external source                    // B02-08

FUNCTION preview(asset, grant):
  verify window, project, file identity and hash; serve approved byte range   // B02-15

FUNCTION saveCanvas(canvas):
  validate node IDs, edges and asset references; publish project snapshot    // B02-16
```

## 并发控制

暂存和探测在写队列外执行，每项目最多两个活跃会话。项目协调器串行提交、校验修订和处理项目关闭。会话在同一运行期间复用暂存文件，项目关闭或会话超时释放资源。进程退出后重开项目会清理该项目的孤儿导入暂存文件。跨进程由项目 owner lock 排他。

## 事务边界

先安全暂存并校验，再同步 Blob 或设备定位文件，最后发布含资产记录及回执的 ProjectState。提交失败可能留下未引用 Blob 或 locator。重定位只原子替换设备定位文件。快照发布前响应取消，发布后以真实提交结果为准。tombstone 与历史 Blob 保留见[本地数据契约](../../../04-技术架构/本地项目与资产契约.md)。

## 幂等与重试

去重候选键为项目、SHA-256 和导入模式。复用既有资产也提交回执。重复或修订冲突的会话保留暂存文件，提交时检查候选仍可用。回执绑定请求指纹，已提交请求支持重放。

## 外部调用与补偿

不适用：首阶段本功能仅本地处理；媒体解析器仍需限制资源消耗。

## 安全与日志

- 只接受 Main 创建的文件授权句柄。
- 授权 token 由 Main 保持已打开的 O_NOFOLLOW 文件句柄，绑定 webContents 与 projectHandle，10 分钟过期；关闭窗口清理 fd。
- 不信任扩展名；校验签名/容器元数据并限制资源。
- 预览使用窗口独立会话内的 `link-media` URL，限制媒体类型、有效期及 GET/HEAD 请求。存储路径在 Main 内解析，内容变更时重新校验 hash。
- 设备 locator 按项目目录身份、项目 ID、资产 ID 和定位 ID 匹配，仅在设备用户数据目录中保存绝对路径。
- Blob 父目录拒绝 symlink，EEXIST 时使用同一文件句柄校验类型、大小和完整 SHA-256。同步 Blob 目录链后发布快照。流式读取以源文件初始大小为上限，导入前后比对大小、mtime、ctime 和 inode。
- 日志记录 assetId、错误类型和字节数，不记录媒体正文或凭证。

## 发布与回滚

- AssetRecord schema 带版本。
- 缩略图可重建；原始资产 Blob 不随缓存清理。
