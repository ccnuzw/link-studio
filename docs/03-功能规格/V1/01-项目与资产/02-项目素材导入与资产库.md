## 目标

创作者能把图片、视频和音频安全纳入本地项目资产库，并在画布和输出流程中稳定引用。

## 功能边界

包含：系统文件选择/拖放、格式与大小检查、资产登记、缩略图/元信息、预览、引用和重复检测。

不包含：云端共享同步、在线对象存储和高级 DAM（V3/后续）。

## 需求说明

### 用户故事

作为创作者，我希望把来源媒体组织到项目并安全复用，以便画布和生成任务使用稳定资产引用。

### 业务规则

1. 导入必须通过用户明确选择或系统拖放授权。
2. 默认复制到项目资产库；用户可显式选择引用原文件，引用外部路径需可见并支持重新定位（D006）。
3. 资产 ID 稳定，节点引用 ID，不依赖临时文件路径。
4. 删除资产前检查引用；原始源文件不得因删除项目引用而误删。

### 主流程

1. 用户选择或拖入媒体。
2. Main 检查授权、文件类型/大小和可读性。
3. 资产服务登记、计算指纹、生成元信息/缩略图。
4. 资产出现在项目库并可被画布引用。

### 异常与边界

- 不支持/损坏/超限媒体拒绝导入并保留清晰原因。
- 磁盘不足或复制中断时不得登记为完整资产。
- 哈希重复时提供复用已存在资产或保留独立记录的明确选择；不得覆盖已有资产。
- 任一创作或运行任务引用存在时拒绝移除；先通过对应域解除引用，再将资产 tombstone，不自动级联清理，也不删除外部原文件。

### 页面与交互

资产库展示缩略图、类型、时长/尺寸、来源和文件大小；提供导入、预览、定位引用和删除/移除入口。

## 接口契约

S1 使用 `assets.import/getImport/resolveDuplicate/commitImport/cancelImport/list/getPreview/relocate/remove`，以及 dialogs.selectMedia；导入会话、去重和提交签名见 [桌面 API](../../../04-技术架构/桌面API与任务契约.md)。

| 字段 | 位置 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- | --- |
| projectId | IPC | string | 是 | 当前已打开项目 |
| authorizedFileToken | IPC | opaque string | 是 | Main 创建的临时授权句柄，不接受任意 Renderer 路径 |
| importMode | IPC | enum | 否 | copy / reference；缺省为 copy |

### 错误矩阵

| 错误键 | 场景 | 用户提示 |
| --- | --- | --- |
| ASSET_TYPE_UNSUPPORTED | 类型不支持 | 该文件类型暂不支持 |
| ASSET_SIZE_LIMIT | 超过限制 | 文件超过当前导入限制 |
| ASSET_READ_FAILED | 文件不可读/损坏 | 无法读取此媒体文件 |
| ASSET_STORAGE_FAILED | 写入失败 | 导入未完成，原文件未更改 |
| ASSET_IN_USE | 删除时仍被引用 | 先移除画布或分镜中的引用 |

错误 code 直接使用字符串，补充 token/引用变更/缺失/会话错误见桌面 API；媒体类型、资源限制和并发见 [本地数据契约](../../../04-技术架构/本地项目与资产契约.md)。

## 数据与事务

| 数据 | 操作 | 字段 |
| --- | --- | --- |
| Asset Record | R/W | assetId、sha256、mediaType、size、metadata、storageRef、sourceRef、createdAt |
| Blob | R/W | 默认项目内副本；高级模式可记录外部引用 |
| Thumbnail | W | assetId、variant、cache path |

写入顺序必须确保 Blob 完整且校验通过后才提交 Asset Record；缩略图失败不应使原资产丢失。

### 状态与生命周期

`selected -> validating -> copying/indexing -> ready`；重复/修订冲突等待显式解决；失败或取消清理未提交临时文件。并发默认 2；越过快照提交点后不能伪称取消成功。

## 验收标准

#### AC01 导入并引用媒体

Given 用户已打开本地项目并选择支持的媒体文件。

When 导入完成。

Then 资产库显示有效资产 ID 和元数据，画布可通过 ID 引用它。

#### AC02 中断导入不登记半成品

Given 大文件导入期间磁盘写入失败或用户取消。

When 导入流程结束。

Then 资产不处于 ready，临时文件按策略清理，源文件保持不变。

#### AC03 重复文件处理

Given 项目已包含内容相同的资产。

When 用户再次导入该文件。

Then 系统显示重复项并允许复用或保留独立记录，不产生无提示覆盖。

#### AC04 被引用资产移除保护

Given 资产仍被画布节点或分镜引用。

When 用户请求移除该资产。

Then 系统拒绝移除正在使用的资产或要求先解除引用；不删除项目内 Blob 或外部原文件。

#### AC05 默认复制后可独立使用

Given 用户导入媒体且没有选择高级外部引用模式。

When 导入成功后源文件被移动或删除，再次打开项目。

Then 项目使用自己的完整副本正常预览，资产记录 importMode 为 copy，不依赖源路径。

#### AC06 外部引用丢失后重新定位

Given 用户显式选择 reference 模式，之后源文件被移动。

When 打开项目并使用该资产。

Then 显示缺失状态且不静默替换；用户重新选择文件后校验内容并更新引用；移除引用不删除外部文件。
