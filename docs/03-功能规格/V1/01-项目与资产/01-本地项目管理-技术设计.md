# 01 本地项目管理 - 技术设计

来源：[需求](01-本地项目管理.md#需求说明) · [接口](01-本地项目管理.md#接口契约) · [数据](01-本地项目管理.md#数据与事务) · [验收](01-本地项目管理.md#验收标准)

## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 崩溃时快照截断 | 高 | 临时写入、fsync/原子替换、保留上一代有效快照 | D004 |
| Renderer 越权读写路径 | 高 | Main 维护授权项目句柄，IPC 不接受任意绝对路径 | D001 |
| 多窗口/实例丢失更新 | 高 | 项目单写所有权、owner 校验和 revision 乐观锁 | D009 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `createProject(input)` | 目录经对话框授权且名称有效 | 初始 ProjectState revision=1 | 独占创建目录 | operationId + requestHash 去重 |
| `saveSnapshot(projectHandle, expectedRevision, payload)` | 项目打开、owner 有效、schema 合法 | revision + 1，快照完整可读 | 不可变快照发布 | 同 operationId 同请求返回首次结果 |
| `recoverProject(projectId)` | 存在 manifest 或快照 | 返回最近一个校验通过的版本 | 可写恢复副本 | 是 |
| `openProject(directoryToken)` | 系统授权目录 | 取得唯一 owner 或激活已有窗口/返回占用 | 原子申请跨进程占用，登记窗口 | 目录身份幂等 |

## 伪代码

```text
FUNCTION saveSnapshot(project, expectedRevision, payload):
  IF project not authorized: RETURN PROJECT_PATH_DENIED       // B01-01
  IF caller owner is not current owner: RETURN PROJECT_IN_USE // B01-06
  IF payload schema invalid: RETURN PROJECT_SCHEMA_INVALID    // B01-02
  IF current revision != expectedRevision: RETURN CONFLICT    // B01-03
  serialize to temporary file                                 // B01-04
  flush and atomically publish immutable snapshot; manifest is rebuildable // B01-05
  return new revision

FUNCTION openProject(directoryToken):
  resolve canonical directory identity from authorized token
  IF same instance owns directory: focus existing window; RETURN // B01-07
  IF atomic ownership acquisition fails: RETURN PROJECT_IN_USE // B01-08
  IF stale owner record exists: recover only after confirming previous owner exited // B01-09
  recover valid project state; register owner token and window // B01-10
```

## 并发控制

| 场景 | 冲突点 | 控制方式 | 失败策略 |
| --- | --- | --- | --- |
| 同实例重复打开 | 规范化目录身份 | Main 窗口注册表 | 激活原窗口 |
| 跨实例竞争打开 | 同一目录的 owner | 原子跨进程占用；锁原语待平台验证 | PROJECT_IN_USE，不创建第二个写窗口 |
| 自动保存/任务结果/导出入库 | 当前 revision | 同一 owner 下的项目写队列和 CAS | 拒绝陈旧更新，重新读取合并后提交 |

会话所有权贯穿项目可写生命周期；每次写入还需要短事务锁，不能混为同一把锁。短事务锁不包模型网络请求和媒体计算。关闭时先停止接受新写入并排空写队列，再释放会话所有权；不可留下仍会落盘的旧 Worker。

路径身份应解析真实目录并处理平台大小写/别名语义，不只比较字符串或 projectId。锁文件只用于诊断，不以存在文件或超时作为唯一存活证据；崩溃后的旧记录清理必须在新进程取得原子所有权后进行。owner token 用于拒绝迟到事件；项目被外部删除/替换后停止写入并重新授权，不对网络共享盘宣称可靠锁语义。

## 事务边界

- 范围：序列化临时 ProjectState、校验、原子发布终态快照；manifest 是提交后可重建信息，不是事务提交点。
- 隔离级别：本地文件事务；具体原子替换和目录 fsync 需按平台验证。
- 失败回滚：临时文件清理，旧快照保持有效。

## 幂等与重试

- 幂等键：项目目录会话身份 + operationId，绑定 requestHash；回执存在 ProjectState；expectedRevision 用于冲突检测，不作为幂等 ID。
- 重复请求不得生成两个不一致 revision。

完整字段、提交点与恢复顺序见 [本地项目与资产契约](../../../04-技术架构/本地项目与资产契约.md)；S1 技术实现不得另外写一套 manifest 权威源。

## 外部调用与补偿

不适用：本功能不调用外部服务。

## 安全与日志

- 日志不写入项目正文、用户媒体内容、绝对路径中的敏感用户名以外的完整路径或令牌。
- Main 校验项目授权根目录，拒绝路径穿越和越权 symlink 目标。

## 发布与回滚

- 前置条件：项目 schema 带版本号并能识别未知版本。
- 回滚方式：保留上一版快照；未知 schema 只读打开或阻止写入。
- 监控指标：保存耗时、失败率、恢复成功率。
