## 目标

创作者能预览项目中的图片/视频/音频资产，并将首期支持的镜头/媒体组合导出为可播放视频文件。

## 功能边界

包含：媒体预览、视频镜头排序、顺序拼接为 MP4、可选 BGM、导出任务、进度、取消、错误提示和导出结果入资产库/指定目录（D008）。

不包含：完整多轨非线性编辑、转场特效、专业调色和全部视频编码矩阵。图片转动态镜头和逐镜头复杂裁剪不作为本次顺序拼接的首期承诺。

## 需求说明

### 用户故事

作为创作者，我希望检查生成媒体并输出可播放文件，以便完成一次本地视频创作闭环。

### 业务规则

1. 预览使用受限的本地资产 URL/协议，不向 Renderer 暴露任意文件读取。
2. 转码/合成在独立 Worker/Utility Process 执行。
3. 导出写临时目标，完成并校验后才提交最终文件。
4. 已存在目标文件必须询问覆盖/另存，不可静默覆盖。
5. FFmpeg 参数采用参数数组，不拼接 shell 命令；进程资源、时长和输出大小需限制。
6. 输入为显式排序的视频镜头列表，输出顺序与配方一致，不依赖资产库排序；输出格式为 MP4。
7. BGM 为可选项目音频资产；不选 BGM 时保留源视频音轨，无音轨镜头以静音对齐。
8. 工程提案：统一画面尺寸/帧率/音频采样参数后拼接；保持画面比例并留边，避免静默拉伸。BGM 默认与源音混合，长于成片则截断，短于成片则播放结束，不默认循环；提供源音和 BGM 音量控制。具体编码配置与混音效果在媒体验证阶段确认。
9. 导出创建有序输入、BGM、参数和素材版本的不可变快照；导出期间调整画布或镜头列表不改变本次输出。项目写入通过单一协调器提交。

### 主流程

1. 用户选择视频资产组成镜头列表并排序，可选一个 BGM 音频资产。
2. 选择目标路径和首期支持参数。
3. Main 校验引用、磁盘空间和目标覆盖策略。
4. Media Worker 执行，Renderer 显示进度和可取消状态。
5. 输出校验成功后原子移动到最终路径并可导入资产库。

### 异常与边界

- 缺失源资产在启动导出前报告。
- Worker 崩溃/FFmpeg 失败保留日志 ID 和安全错误信息，清理临时产物。
- 用户取消后确保子进程终止及临时文件状态明确。
- 磁盘不足时不覆盖已有目标文件。

### 页面与交互

预览区播放/暂停/定位；基础成片面板支持镜头排序、移除和 BGM 选择；导出对话框显示 MP4 格式、分辨率、质量及音量等实际支持参数。首期编码参数集待验证。

## 接口契约

IPC 草案：previewAsset、startExport、cancelExport、getExportJob、subscribeExportEvents。

| 字段 | 位置 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- | --- |
| projectId | IPC | string | 是 | 当前项目 |
| sourceAssetIds | IPC | string[] | 是 | 按镜头播放顺序排列的视频资产，属于当前项目且有效 |
| bgmAssetId | IPC | string | 否 | 当前项目可读音频资产；为空不添加 BGM |
| audioMix | IPC | object | 否 | 受限源音/BGM 音量参数；默认策略见业务规则 |
| outputTargetToken | IPC | opaque token | 是 | 来自系统保存对话框，不接受任意不受限路径 |
| exportProfile | IPC | object | 是 | 仅允许白名单参数 |

### 错误矩阵

| 错误键 | 场景 | 用户提示 |
| --- | --- | --- |
| EXPORT_SOURCE_MISSING | 输入资产缺失 | 检查项目素材引用后重试 |
| EXPORT_TARGET_EXISTS | 目标已存在 | 选择覆盖或另存为 |
| EXPORT_MEDIA_UNSUPPORTED | 输入/编码不支持 | 当前媒体组合无法按此配置导出 |
| EXPORT_WORKER_FAILED | 转码失败/崩溃 | 导出失败，可查看诊断并重试 |
| EXPORT_CANCELLED | 用户取消 | 导出已取消，目标文件未被替换 |

## 数据与事务

| 数据 | 操作 | 字段 |
| --- | --- | --- |
| Export Job | R/W | exportId、projectId、orderedInputs、bgmAssetId、audioMix、profile、sourceRevision、state、progress、outputRef、errorKey |
| Output File | W | 临时路径、最终路径授权、size、duration、hash |

目标替换必须使用备份/原子 rename 策略；取消和失败时最终文件不被半成品覆盖。

### 状态与生命周期

`queued -> preparing -> running -> validating -> succeeded`；可取消阶段进入 cancelling/cancelled；失败进入 failed，非法状态转换拒绝。

## 验收标准

#### AC01 导出可播放文件

Given 项目包含规格支持的源素材和有效导出配置。

When 用户启动导出并等待完成。

Then 输出文件通过媒体校验，可由应用预览，并显示明确路径/资产记录。

#### AC02 不静默覆盖现有文件

Given 用户选择的目标路径已有文件。

When 用户启动导出。

Then 系统先要求覆盖确认或另存为，未确认时现有文件字节不变。

#### AC03 取消/失败不留下伪成功文件

Given 导出正在运行。

When 用户取消或 Worker 失败。

Then 任务状态如实终止，临时文件清理/保留策略明确，最终目标不存在半成品。

#### AC04 Worker 不阻塞 UI

Given 大于最小测试样本的导出任务。

When 导出运行。

Then UI 可响应取消/导航，Main 事件循环未被同步转码阻塞。

#### AC05 多镜头按指定顺序成片

Given 项目有三个可区分的视频镜头，且包含不同分辨率/帧率和无音轨素材的测试样本。

When 用户指定播放顺序并导出 MP4。

Then 成片按指定顺序播放、时长符合镜头总时长的编码容差，画面比例和音画同步符合导出配置；无音轨镜头不导致拼接失败。

#### AC06 可选 BGM 与音频时长处理

Given 同一视频镜头列表和一段可读 BGM，测试样本分别覆盖 BGM 长于/短于成片及无源音镜头。

When 用户分别导出不含 BGM 和含 BGM 的版本。

Then 不含 BGM 的版本保留源音；含 BGM 的版本按显示的混音配置输出，BGM 不改变成片总时长，短音频不导致视频提前结束，长音频不延长成片。

#### AC07 导出输入快照稳定

Given 导出任务已固定镜头顺序、BGM、参数及输入版本。

When 用户在导出过程中修改项目镜头列表或画布。

Then 当前导出仍使用原快照；输入资产在使用期间不被清理，输出登记经项目写入协调器提交，不覆盖后续项目修改。
