## 当前门禁

D011 将共享引擎、设置/核心画布双助手列为 V1 主线；不是可选 Provider 作者工具。专业域分期时同步迁移相应 Agent，整体覆盖与例外见完整迁移设计。

这些规格是需求起草稿（Draft）。Provider 插件扩展及 Agent/人工双入口、素材默认复制、有条件任务恢复、顺序拼接 MP4 与可选 BGM、同项目单写窗口已确认；插件运行时与兼容性、目录与锁、任务状态和错误码、编码及混音参数仍待验证或细化，不可直接视为实现合同。

本轮已补 [实施批次](../../04-技术架构/实施基线与开发批次.md)、S1 数据/API 和目标测试命令。可以开始 M0 工程/兼容性验证；S1 的契约是该验证输入，实际工具链和锁/落盘结论就绪后再将该批规格改为 Ready，不要求 V2/V3 详细规格先完成。
