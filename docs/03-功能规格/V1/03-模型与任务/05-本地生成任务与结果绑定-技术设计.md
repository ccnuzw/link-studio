# 05 本地生成任务与结果绑定 - 技术设计

## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 外部调用超时后重复生成 | 高 | idempotency key、查询能力、outcome_unknown | D002、D004 |
| 多任务更新同一节点 | 高 | jobId/revision 校验，结果追加而非覆盖 | D001 |
| 恶意/损坏输出写入项目 | 高 | 大小、类型、容器和 hash 校验，临时提交 | D002 |
| Main 阻塞 | 高 | Utility Process/Worker 与有界事件通道 | D001 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `submitJob(input)` | 项目/节点/Provider/能力合法 | 持久化 jobId 后入队 | journal 写入、网络请求 | jobId/idempotencyKey 唯一 |
| `commitOutput(jobId, tempOutput)` | 输出已完整下载 | AssetRecord + node binding + succeeded | 文件移动和本地记录写入 | jobId + output index 唯一 |
| `recoverJobs()` | journal 可读 | 安全恢复或标记 unknown | 已启用插件 query（仅支持时） | 重复运行安全 |

## 伪代码

```text
FUNCTION submitJob(input):
  IF capability or inputs invalid: RETURN JOB_INPUT_INVALID   // B05-01
  IF provider unavailable: RETURN JOB_MODEL_UNAVAILABLE       // B05-02
  persist job with idempotency key before network call         // B05-03
  response = provider.submit(job)
  IF timeout and acceptance unknown: mark outcome_unknown; RETURN // B05-04
  IF task handle exists: persist handle/state and exact plugin version // B05-05
  IF response is async: query until terminal with original plugin; otherwise retain unknown if query unavailable
  IF terminal failed or cancellation confirmed: persist terminal status; RETURN
  download to temp and validate                                // B05-06
  atomically register asset and bind node                      // B05-07
```

## 并发控制

- JobStore 对 jobId 状态转换做 CAS，拒绝过期事件。
- 同一节点可以存在多个历史任务；任务完成不覆盖用户后续编辑的数据，只追加结果引用。
- 限制全局和按 Provider 并发数，默认值需按实际 Provider 能力配置。

## 事务边界

Provider 调用在本地持久化事务之外。成功输出 commit：临时输出校验、Blob 原子移动、AssetRecord 和 NodeBinding/Job succeeded 写入需有恢复日志；文件和 JSON/SQLite 元数据无法共事务时通过 journal 补偿。

## 幂等与重试

- 客户端 jobId 在发请求前持久化。
- 若 Provider 支持幂等键则传递；不支持时不宣称端到端 exactly-once。
- 查询/下载可重试；提交仅在明确未发送或 Provider 幂等保证时自动重试。
- 结果未知时不重复扣费/生成，等待查询或用户确认策略。

## 外部调用与补偿

- connect/read/overall timeout 分开定义；重试指数退避和次数待协议规格。
- 任务输出 URL 视为不可信，限制 scheme/host、重定向、响应体大小和落盘路径。
- Worker/应用重启后根据 durable handle 和已批准插件版本调用 query；不支持查询的 Provider 进入 outcome_unknown，不自动重放 submit。
- 若 Provider 产生费用但本地提交失败，保留 task handle 和诊断以便重新下载。

## 安全与日志

- Worker 通过 Main 安全句柄读取 secret，不能通过普通 IPC 回传 secret。
- Prompt/素材 URI/Authorization 默认不写日志；错误消息需脱敏。
- 本地 Provider 的网络策略和 redirect policy 继承 V1-FR-004。

## 发布与回滚

- Job schema 带版本，升级时保留未知字段。
- Worker 版本不兼容的任务暂停并保留输入，不自动重放。
- 监控任务数、状态滞留、unknown 数、下载失败和 Worker 崩溃。
