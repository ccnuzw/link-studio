# 03 创作画布与节点保存 - 技术设计

来源：[需求](03-创作画布与节点保存.md#需求说明) · [接口](03-创作画布与节点保存.md#接口契约) · [数据](03-创作画布与节点保存.md#数据与事务) · [验收](03-创作画布与节点保存.md#验收标准)

## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 自动保存丢失并发更改 | 高 | revision 乐观锁、保留 dirty buffer | D001 |
| 上游 schema 迁移丢字段 | 高 | 原始未知字段保留、迁移 fixture | D001 |
| 大节点 payload 卡 UI | 中 | Blob 外置、IPC payload 上限和批量操作 | D001 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `applyCanvasOperations(projectId, baseRevision, operations)` | 项目打开、操作通过 schema | 新 revision 和规范化快照 | 写本地项目 | operationId 幂等，待确认 |

## 伪代码

```text
FUNCTION applyCanvasOperations(baseRevision, operations):
  IF operations invalid: RETURN CANVAS_OPERATION_INVALID       // B03-01
  IF referenced assets unavailable: RETURN REFERENCE_MISSING   // B03-02
  IF current revision != baseRevision: RETURN REVISION_CONFLICT // B03-03
  apply allowlisted operations to draft                         // B03-04
  persist new snapshot atomically                               // B03-05
  return revision and snapshot
```

## 并发控制

基于 `baseRevision` compare-and-swap；不支持 silent last-write-wins。自动保存队列每项目串行化。

## 事务边界

操作校验、draft 应用、快照原子写和 revision 更新构成一次本地提交；写入失败保留前一快照和 Renderer dirty buffer。

## 幂等与重试

operationId 作为重放去重候选；重复成功操作返回首次 revision，细节待接口规格确认。

## 外部调用与补偿

不适用：画布服务不直接调用网络 Provider。

## 安全与日志

IPC 只接收白名单结构化操作；节点数据大小、字符串长度和数组深度设置限制。日志不落画布正文。

## 发布与回滚

迁移前保留原始快照；新 schema 写入前生成可恢复备份，迁移失败只读打开旧格式。
