## 目标

创作者能在本地无限画布中组织文本、图片、视频、音频和生成节点，保存布局与节点关系并在重启后恢复。

## 功能边界

包含：React Flow 画布、script/image/video/audio 四类核心节点增删改、连线、选择/移动、分组、视口、自动保存、撤销恢复的基础边界；具体首迁行为见 [首期交互与节点迁移](../../../04-技术架构/首期创作交互与节点迁移.md)。

不包含：多人实时协作、Agent 任意改图、完整短剧/营销/导演台专属交互（后续阶段）。

## 需求说明

### 用户故事

作为创作者，我希望把脚本、素材与生成任务放在可连接的画布上，以便组织和复用创作流程。

### 业务规则

1. 节点引用资产 ID，不将大型媒体内容复制进画布快照。
2. 数据模型应携带 schema version，并与上游 video-canvas 画布格式建立显式迁移映射。
3. 持久化快照和 Renderer 暂存状态分离；保存成功前展示 dirty 状态。
4. 画布编辑和任务状态分离；任务状态通过 jobId 关联，不作为不可恢复的 UI 临时状态。
5. 同项目单写窗口；自动保存和后台任务回写经项目协调器提交，不能绕过 owner/revision 校验（D009）。

### 主流程

1. 用户打开项目画布。
2. 创建节点、导入/选择资产并编辑数据。
3. Renderer 将变更提交给本地画布服务。
4. 服务端校验节点/边/资产引用后持久化新 revision。
5. 重启后恢复节点、边、分组和 viewport。

### 异常与边界

- 未知节点类型以只读/兼容占位显示，不可静默丢弃。
- 保存冲突不得覆盖较新 revision。
- 删除被任务或分镜引用节点时需保留历史任务/资产，引用清理策略待定。
- 高频拖动应合并保存，但关闭项目前须 flush。

### 页面与交互

主创作工作区包含节点面板、画布、可折叠属性面板和任务入口；保存状态可见。

## 接口契约

IPC 需要 `readCanvas`、`applyOperations`、`saveViewport`、`undo/redo` 或等价域 API；通道和操作 union 待设计冻结。

| 字段 | 位置 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- | --- |
| projectId | IPC | string | 是 | 已打开项目 |
| expectedRevision | IPC | integer | 是 | 正整数，与当前快照匹配 |
| operations | IPC | array | 是 | 有限白名单操作，不接收任意文件路径 |

### 错误矩阵

| 错误键 | 场景 | 用户提示 |
| --- | --- | --- |
| CANVAS_REVISION_CONFLICT | revision 已变化 | 画布已更新，请恢复或合并更改 |
| CANVAS_SCHEMA_UNSUPPORTED | 不支持的新 schema | 该画布版本较新，已以只读方式打开 |
| CANVAS_REFERENCE_MISSING | 节点引用的资产不存在 | 部分媒体引用缺失 |

## 数据与事务

| 数据 | 操作 | 字段 |
| --- | --- | --- |
| Canvas Snapshot | R/W | schemaVersion、revision、nodes、edges、viewport |
| Canvas Operation Journal | W/R | operationId、baseRevision、operation、timestamp |
| Node/Edge | W | id、type、position、data、source/target |

约束：节点/边和 revision 更新必须作为一次逻辑提交；画布不得包含密钥或媒体 Blob。

### 状态与生命周期

`loaded-clean -> dirty -> saving -> loaded-clean`；发生冲突进入 `conflicted`，失败进入 `save-error` 并保留本地暂存修改。

## 验收标准

#### AC01 保存并恢复画布

Given 一个已打开本地项目。

When 用户创建文本和媒体节点、连线、移动视口后关闭并重开项目。

Then 节点数据、关联、位置和 viewport 恢复一致。

#### AC02 保存冲突不静默覆盖

Given 两个写入方基于同一 canvas revision 修改。

When 后提交方保存。

Then 系统返回冲突并保留其本地修改供处理，不覆盖已提交快照。

#### AC03 未知节点兼容

Given 项目包含当前版本不认识的节点类型。

When 打开画布。

Then 未知数据不会被静默删除，用户可见兼容提示。
