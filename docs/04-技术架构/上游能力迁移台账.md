# 上游能力迁移台账

基线：video-canvas `f0b8ced3687b22de6af0358c682c5e768001ff4f`；Fynvra `d1ef382ccacab73813a81949a258aa6a151e2572`。下表路径相对各自仓库，已经对照本次本地快照核验。它是能力域级台账，不宣称已穷尽每个子按钮；每批实施需把子能力、路由、测试和复制来源展开到该批记录。实现状态仍只维护在版本实现状态表。

迁移方式：“迁入”表示复用 UI/领域语义并改依赖；“替换”表示桌面能力取代 Web/服务端依赖；“保留服务”表示后续官方端；“不搬入”须说明去向，不能等同整体能力目标被删除。
