# 功能覆盖与迁移例外

依据 D011：最终尽可能实现 video-canvas 全部主线及主要功能；完整迁移设置/画布 Agent 的机制与交互。分阶段只改变顺序，不能自动删减最终范围。源码基线与能力域见 [迁移台账](上游能力迁移台账.md)，Agent 36 项工具逐项映射见 [完整迁移设计](内置Agent完整迁移设计.md)。

## 覆盖验收口径

每个域开发前展开“上游路由/入口 → 用户任务 → 子功能/工具/状态 → 数据/API/依赖 → 桌面替代 → 验收/测试”；交付时逐项对照：人工路径、Agent 路径（上游具备时）、异常恢复和已有数据兼容。保留截图样式但删业务动作不算完成；只迁前端、工具声明不含执行器不算完成；mock 不算真实供应商兼容。

本机模式下不适用的官方管理能力可留在独立官方后台，不要求嵌入创作者桌面。改变数据源/执行位置是适配，不自动认定功能删减。现阶段没有声称台账已穷尽所有子按钮；发现新子能力加入台账并明确去向，不默认排除。

新发现细节及上游规划的证据分级见 [子能力补充与渐进落盘计划](子能力补充与渐进落盘计划.md)。同节点多结果、技能场景开关和片场提示词转写按源码现状迁移；仅有设计线索的用户版本历史、明确搁置的通用技能脚本分别保留为候选/参考，不能与既有功能混记。

## 例外与改造登记

| ID | 上游行为/能力 | 类别 | 处理与原因 | 验收/去向 |
| --- | --- | --- | --- | --- |
| EX-01 | 所有创作入口先经站点账号登录 | 替代 | 本地项目/自定义模型允许未登录；官方能力局部登录 | V1 本地 E2E + 后续官方授权 |
| EX-02 | 云画布/资产/队列为所有创作的权威源 | 替代 | 本机项目/Blob/JobRuntime 取代；不打包 Go/Postgres/Redis 业务后端 | 本地保存/恢复/生成/导出语义保留 |
| EX-03 | 前端持有服务器 URL 即可把参考素材交给远端模型 | 替代 | 显式 Host 上传/直传/用户存储，不自动上传官方 | 参考素材传输与签名/凭证隔离验证 |
| EX-04 | admin Agent 可改官方定价/渠道、查询全站用户与审计 | 保留到官方后台 | 本机只作用个人设置/授权数据；无官方管理权限 | 本机变更单 V1；官方管理员工具随官方后台 |
| EX-05 | 短剧/营销/角色/分镜/导演台等完整专业域 | 分期，非排除 | V2 迁移域时同步接入对应 Agent；本版不支持的节点保留数据 | 对应域人工+Agent 主线验收 |
| EX-06 | 多人实时协作、共享/组织、自托管 | 边界保留 | 共享/组织 V3，实时同编不预先承诺，工作室自托管不在当前产品范围 | 以已确认产品边界为准，非据此删本地创作能力 |
| EX-07 | 后台全局技能/步骤/版本分发管理 | 适配与分期 | 本机迁入导入/版本/启用/资源及运行观测；官方全局发布留后台 | 记录本机/官方权限差异，不能整域删除 |
| EX-08 | 任意技能脚本执行、3D Agent 完整编辑 | 未证实为既有能力 | 历史设计中技能脚本执行搁置；上游 director 不可直接 @ 引用。当前不假装已有 | 未来扩展另议；code-mode 受限工具编排必须保留 |

没有上述理由的新功能不得仅以“复杂/不在 MVP”为永久排除依据。新增例外应写明与桌面或既有产品决策的具体冲突、保留的等效用户任务和替代验收，涉及删减主功能需用户决定；一般实现路径由工程处理。

## 本轮纠偏记录

设置助手不再等同插件作者：包含当前页上下文、配置/模型能力诊断、资源检索、变更单、专用密钥与真实试跑。画布助手不再整体延到 V2：V1 必须包含核心画布理解/编辑/布局、媒体生成审批/任务等待、插话/恢复/撤销和统一会话 UI；专业域工具随 V2 扩展。

实现状态只写版本实现状态表；台账记录覆盖和去向，不另报“已迁移百分比”。
