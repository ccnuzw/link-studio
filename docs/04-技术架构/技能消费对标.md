# 技能消费契约（video-canvas ff4070c7）

- 六个独立场景，无全局总开关。旧库的 `enabled` 只与 `agent` 同时为真时表示画布可用，短剧五项按原有效范围保留。任何有效场景仍在用时禁止整项删除。
- 画布和短剧对话使用 Agent 场景的只读目录。设置助手不消费技能。正文和资源是参考数据，绝不执行脚本。同一运行首次成功读取固定版本；撤销场景立即生效。
- 短剧生产按环节选择，冻结方法、版本与正文引用的文本，不把技能包直接传入图像、视频模型。分镜图模板、结构化格式化与个人提示词不是可执行技能。
- 营销的 facts、reverse、follow、create 按环节绑定方法，而非给每个模型勾选技能。有效绑定以同环节、同候选版本、通过格式校验且 24 小时内的成功试跑为依据。版本失效回退内置；不以其他模型试聊代替业务格式校验。

## 下游接入

| 使用者 | 入口与边界 |
| --- | --- |
| 本机设置 | 技能版本独立预检、导入、预览、导出和删除。数据在本机 SQLite；不模拟服务器用户、对象存储 GC 或官方分发。该上游提交没有预装技能包。 |
| 对话模型 | 画布与短剧共用 `skill_search` / `skill_read`；`id` 兼容既有消息，`name` 支持按名称读取。正文和附件分页返回，`nextOffset` 是下一段字节偏移。按运行释放固定版本，再次读取仍检查权限。活动记录显示实际版本和文件。 |
| 短剧生产 | `plan/scripts/assets/asset_prompts/video`，正文及引用上限 16,000 字，不含脚本。既有项目和任务使用快照，重跑不静默替换。 |
| 营销生产 | 后续业务在任务开始时调用主进程 `SettingsRegistry.runBoundMethod(library, step, model, input, signal)`，传入业务输入而非样例；返回通过校验的 `output` 或失败原因，以及绑定/回退身份。业务任务应保存这些结果。本批不交付商品项目、投放或出片工作室。 |
| 图像／视频／音频模型 | 不加通用技能开关。事实卡用商品图；参考片拆解用支持的视频或截帧；跟拍和创意脚本用结构化输入。Seedance、H3、generic 格式化器为代码，可在环节技能页预览；不读技能，预览不花费模型额度。 |

## 来源与验收

营销四套协议、校验、方法、样例、格式化器及共享协议代码取自 `video-canvas@ff4070c7b23581b1a79eacbfeddc56f836562377` 的 `backend/internal/{marketing,stepkit}`。桌面版替换 Go 服务依赖为限定操作的本机 runner 和既有模型网关；样例媒体使用 base64 无损封装。上游 MIT 许可保留于 `resources/provider-plugins/UPSTREAM-LICENSE`，方法署名保留于 `packages/provider-runtime/runner/marketing/methods/NOTICE.md`。

- 技能管理与运行：`tests/unit/skills.test.ts`、`tests/integration/skills-agent.test.ts`、`tests/e2e/skills.spec.ts`。
- 模型协议与失败重写：`tests/integration/settings.test.ts` 的「营销技能试跑」。使用本机模拟模型；不代表已验证商业模型输出质量。
- 短剧生产快照：`tests/integration/drama.test.ts`。短剧五环节与营销四环节的绑定机制不可互换。
