# 桌面首屏与共用样式改版规划

2026-11-23，规划与诊断。桌面依据为 `32ae2e2` 及当日工作树。首页参考本地 `video-canvas@ff4070c7`，已对拍的画布组件沿用[各项记录指定的提交和场景](画布逐项对照与像素级复刻方案.md)。两个版本分别用于首页设计和既有组件回归。

## 入口与组件来源

| 场景 | 桌面行为 | 视觉与交互依据 |
| --- | --- | --- |
| 首次启动 | 在「开始创作」中展示画布和已验收的短剧入口，同屏提供「打开已有项目」。选定方式之后再填名称、选目录。取消时保留所选方式。 | 对照上游 `web/src/pages/home/layout.tsx`、`components/home/segmented.tsx`、`canvas-tab.tsx` 和 `drama-tab.tsx` 的侧栏、分段控件、新建卡及间距。使用现有灵可品牌资源。 |
| 回访 | 最近项目提供一键继续、父目录和移除最近记录。打开项目失败时在对应行显示原因。 | 复用上游首页最近作品卡与紧凑列表。项目没有封面时用已有占位图形。 |
| 项目中切换 | 短剧可从首页直达，项目内用已有项目菜单切换。素材与任务优先复用已有工具栏入口和提示。新建操作写清是否会创建本地项目。 | 画布左上项目栏、左侧工具栏、保存指示和快捷键沿用已对拍布局。先通过首页解决发现问题，避免给编辑区重复增加常驻栏目。 |
| 设置 | 区分「模型与渠道」和「新节点默认模型」。技能、适配器属于导航，助手属于辅助操作。从首页进设置返回首页，从项目进设置返回原工作现场。 | 对齐既有渠道页、助手抽屉与画布设置。同一状态只突出一个下一步，复用已有保存、试跑、离开未保存表单和删除确认。 |

## 共用样式与两套主题

1. 按钮、图标按钮、分段选择、开关、菜单、弹窗、抽屉和通知逐项登记「上游参照、桌面实现、调用方、浅深状态」。优先复用现有 `ChoiceButton`、`SettingsSwitch`、`CanvasControlTip` 等实现。对外观相似但键盘操作不同的控件，保留各自交互语义。图标尺寸、字重、行高、圆角、间距、浮层阴影和动效从对应已对拍组件取值。
2. 相同角色共用主题变量，包括页面背景、面板、浮层、正文、弱文字、分隔线、悬停、选中、焦点和危险操作。首页可沿用上游首页材质，短剧沿用自己的工作台强调色。逐个迁移实际调用方，每次只核对受影响的稳态和交互态。
3. 「跟随系统 / 浅色 / 深色」沿用主进程启动时读取的偏好。应用设置和画布入口读写同一份值，Electron 窗口底色、文档根、原生表单控件、挂到 `body` 的菜单和通知使用同一有效主题。从启动首帧、切换页面、打开抽屉到重启都按此验证，保留现有用户的明确选择。
4. 第一批排查 `styles.css` 中的首页及模型设置、`channel-workspace.css` 的渠道面板和试跑弹窗、`plugin-notice.tsx` 固定深色和 `canvas-toaster.tsx` 的系统主题解析。逐个实测手动主题与系统相反的情况。媒体画面和上游规定的封面遮罩可维持原色，围绕它们的控件与弹层随主题切换。

## 滚动条诊断与修复顺序

`src/renderer/styles.css` 第 550 行附近的选择器在提交 `6a439833` 中被拆开。上一版是 `.node-body { display: block; padding: 15px; }`，当前 `padding: 15px` 命中全局 `body`。独立画布使用 `100svw × 100svh`，因而在向右、向下偏移后超出根视口。短剧内嵌画布已有按容器宽高铺满的规则。

使用无头 Chrome 加载工作树的 `styles.css` 和 `canvas-workspace.css`，挂载最小首页与独立画布壳。测量文档 `scrollWidth - clientWidth` 和 `scrollHeight - clientHeight`，单位为 CSS px。

| 渲染区 | 首页横 / 纵 | 独立画布横 / 纵 | 仅在夹具里移除 body 内边距后 |
| --- | --- | --- | --- |
| 1024 × 700 | 0 / 30 | 15 / 30 | 两种壳均为 0 / 0 |
| 1440 × 920 | 0 / 30 | 15 / 30 | 两种壳均为 0 / 0 |

1. **先修选择器。** 恢复 `.node-body`，核对文件顶部已有的字段组重置规则。用实际节点验证内边距与控件位置。该改动可独立于首屏重排交付。
2. **再查其他页面的横向溢出。** 首页最小夹具只复现了纵向溢出。对最近项目长路径、渠道表格、打开助手、短剧内嵌画布分别找出超出内容区的元素。依据布局修复宽度、换行或容器约束。最小窗口以实际剩余内容宽度决定助手并排或覆盖。
3. **定义滚动归属。** 独立画布的平移缩放由画布处理。嵌入画布使用插槽尺寸。首页和设置长内容允许纵向滚动，模型表格、任务列表、导演时间线按需在自己的容器内滚动。修复中保留菜单、输入焦点、抽屉末行和操作按钮的可达性。仅隐藏滚动条无法通过尺寸和交互验收。

## 分批交付与验收

| 批次 | 验收场景 | 通过条件 |
| --- | --- | --- |
| P0 视口 | 默认与最小窗口，空画布及带节点画布，短剧内嵌画布，打开助手后收起 | 独立画布根元素两轴溢出均为 0，缩放、拖拽、定位节点时根滚动位置保持 0。嵌入画布贴合插槽。长列表可滚到最后一项。 |
| P1 主题与组件 | 系统浅色下手动深色、系统深色下手动浅色、跟随系统时改变系统外观、重启 | 首页 → 设置 → 菜单或弹窗 → 通知 → 画布全程使用所选主题。逐个检查默认、悬停、焦点、选中、禁用、失败状态。浅深分别留样。 |
| P2 首屏与设置 | 无项目、有最近项目、无渠道、有渠道无模型、窄窗开助手、编辑中返回 | 创作目的地可发现，新建只选一次位置，取消无落盘；返回保留来源。配置界面能看见可执行的下一步，用键盘也能完成保存和返回。 |

像素对照沿用既有夹具、相同状态、尺寸与 DPR，并检查整窗位置及组件裁片。上表的修复前数据来自 CSS 最小夹具。

## 实施结果与验证范围

创作工作台提供画布、短剧、打开项目、最近项目和应用设置。设置按模型与渠道、通用与外观、适配器、技能和诊断分组。设置页记录进入来源，窄窗助手以浮层展开，按 Esc 收起后焦点回到入口。首页、设置和通知使用桌面语义色，主题选择复用已有的 Electron 偏好。

已将节点内边距恢复到 `.node-body`，让画布以宿主宽度布局。渠道搜索框也修正了通用输入框内边距覆盖专用样式的问题。修复前图标覆盖文字起点 14 px，回放现要求两者至少间隔 4 px。

| 正式渲染页面，模拟桌面 IPC | 1024 × 700、1440 × 920 的验证结果 |
| --- | --- |
| 首页与项目切换 | 取消目录选择时保留新建弹窗，短剧创建后进入工作室，最近项目可重开，设置返回后原画布节点可见。 |
| 外观与设置 | 浅色、深色、跟随系统选择生效。渠道侧栏和编辑弹窗背景随主题切换。重载后恢复已选浅色。助手收起后恢复键盘焦点。 |
