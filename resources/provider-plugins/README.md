# Provider 适配器插件

23 份 JS 取自 video-canvas 固定提交，已按目标项目的 Provider Runtime 契约接入为内置适配器。`provenance.json` 记录来源提交和每份文件的 SHA-256；设置页也支持继续导入符合契约的手动版本。上游 MIT 许可见 `UPSTREAM-LICENSE`。

`sora.js` 和 `doubao-video.js` 原文件声明改写自 QuantumNous/new-api-plugins 的 Apache-2.0 版本。保留原文件说明；Apache-2.0 文本见 `APACHE-2.0.txt`。正式分发前仍须核对具体上游版本的版权及 NOTICE 义务，当前本地验证不表示来源审计完成。

插件本身不包含凭证，也不会默认启用任何 Provider 配置。插件在沙箱中只负责请求构造、响应解析和错误分类；网络访问、凭证存储、媒体引用替换、二进制资产入库和配置审批由宿主负责。

## 桌面端兼容性

- 23 个插件及 MIT 许可与来源提交的 Git 对象逐份核对。Sora 和豆包视频保留本地补丁，将供应商确认取消记录为 `cancelled`。
- Vertex 使用服务账号 JSON。提交和查询时由主进程换取令牌，任务状态只保留续跑所需的信息。OAuth 和 GCS 地址随配置授权，跨源请求要求 HTTPS。
- 自定义鉴权支持可选的第二凭证 Secret Key。它和主凭证均由宿主加密保存并按连接共享。设置页仅显示配置状态，连接端点或适配器切换后需要重新授权并填写凭证。
- 适配器管理支持 512 KiB 源码、离线样例检查、钩子覆盖和日志、版本分配、引用保护与批量升级。设置助手提供同一离线检查。模型目录沿用宿主的通用拉取接口，兼容旧插件声明的弃用钩子。
- 本地参考素材可通过 multipart、base64 或 dataUrl 传输。对需要公网地址的素材，可在画布为选中的素材填写供应商可访问的 HTTPS 链接。链接随提交请求发送，开始提交时从任务记录移除。桌面端尚无自动上传签名链接及真人库 `filed` 备案服务。
- 桌面沙箱当前支持 macOS。供应商侧的具体模型、参数组合、额度和服务状态仍需用已授权的真实账户验证。
- 桌面任务保留错误分类和状态恢复策略。原服务的上游错误详情、跨渠道调度和重试策略尚未完整移植。

## 图片、视频和音频对标清单

原项目在 `backend/internal/provider/modelcfg` 中按模型配置参数和素材能力。桌面端按内置适配器和型号提供预设，由画布和主进程共用。模型目录和设置继续接受上游型号或接入点 ID。

| 类型 | 适配器 | 桌面接入要点 |
| --- | --- | --- |
| 图片 | Agnes、百炼、豆包、OpenAI Images、OpenAI 对话生图 | 按型号提供尺寸、比例、画质和张数。多参考图按上限校验。支持 multipart 编辑、JSON 内联图或下载 URL，具体由协议决定。 |
| 视频 | Agnes、百炼、Seedance、海螺、New API | 按协议区分文生、图生或全能参考。参考图、视频、音频按类型和数量筛选。 |
| 视频 | Sora、Google Veo、Vertex AI | 参考图直传。Sora 下载二进制，Veo 请求使用实际图片 MIME，Vertex 走服务账号及 GCS。 |
| 视频 | 即梦、可灵、Vidu、xAI | 即梦按上游实现开放文生。可灵与 Vidu 支持首尾帧，xAI 在对应模型支持视频编辑或延长。 |
| 音频 | 豆包、Incho、SunoAPI Music | 豆包提供音色、MP3/WAV/OGG 和音频参数。Incho 提供生成首数，SunoAPI 提供纯音乐开关。SunoAPI Lyrics 属文本插件。 |

公网链接的可达性、模型账号权限和计费行为需在供应商侧验收。仍沿用上游脚本的限制，包括 OpenAI 对话生图仅解析 URL、Vertex 需要 `storageUri`、即梦图生视频缺失。桌面当前未接入裸 PCM 产物与原项目的完整可配置模型能力表单。
